  3. Tool Call 機制

  Tool 創建 (來源: src/agents/pi-tools.ts:107-149)

    exec?: ExecToolDefaults & ProcessToolDefaults;

  Tool 類別:

  1. Built-in Coding Tools (來自 @mariozechner/pi-coding-agent)
    - exec - 執行 shell 命令
    - read - 讀取檔案
    - write - 寫入檔案
    - edit - 編輯檔案
  2. Clawdbot 專屬 Tools
    - message - 跨頻道發送訊息 (src/agents/tools/message-tool.ts)
    - sessions_spawn - 啟動 sub-agent
    - sessions_list / sessions_history / sessions_send
  3. Tool Policy 系統 (來源: src/agents/pi-tools.policy.ts)
    - 全域 policy、provider policy、agent policy 層層過濾

  activeSession.on('tool_start', (tool) => { /* 追蹤 metadata */ });
  activeSession.on('tool_result', (result) => { /* 解析回應 */ });
  activeSession.on('text_delta', (delta) => { /* 串流文字 */ });

  4. Sub-Agent 系統 (來源: docs/tools/subagents.md)

  // 使用 sessions_spawn tool 啟動背景 sub-agent
  {
    task: "研究某個主題",
    label: "research-task",
    model: "haiku",              // 可用較便宜的模型

    cleanup: "delete"            // 完成後清除
  }

  特點：
  - 獨立 session key：agent:<agentId>:subagent:<uuid>
  - 完成後透過 announce 機制回報主 session
  - 預設最大並發：8 (agents.defaults.subagents.maxConcurrent)
  - Sub-agent 不能再啟動 sub-agent（防止無限遞迴）

  interface WorkflowStep {

    status: 'pending' | 'running' | 'completed' | 'failed';
    agentSessionId?: string;
  }

  async function debugWorkflow(error: HoneybadgerAlert) {
    const steps: WorkflowStep[] = [
      { id: 'analyze', status: 'pending' },
      { id: 'fix', status: 'pending' },
      { id: 'test', status: 'pending' },
      { id: 'pr', status: 'pending' },

    broadcastStatus(steps);

    steps[0].status = 'running';
    const analysis = await query({ prompt: `Analyze error: ${error.message}` });
    steps[0].status = 'completed';

    // Step 2: Fix...
    // ...
  }
